# Medical Insurance Cost Analysis

End-to-end healthcare analytics project: Python data cleaning → SQL business analysis 
→ Tableau dashboard → predictive modeling (Linear Regression, test R² ≈ 0.80).

**Key finding:** Smoking is the single largest cost driver — smokers average 3.8x 
higher charges than non-smokers ($32,050 vs $8,441). The highest-cost segment 
(obese smokers over 50) averages $47,369 — over 5x the baseline.

**Tools:** Python, SQL (SQLite), Tableau, Scikit-learn
